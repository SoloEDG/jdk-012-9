# 余境 · 虚拟艺术馆

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18112 。

## 超清纪念影像导出

在任意参观位置点击场景右上角的相机按钮，可把**当前同一时刻**冻结为可下载的超清影像：

- **平面海报**：与实时画面同镜头的三维渲染 + 作品档案、讲解对应段落、同框作品与收藏注记。
- **环视全景**：360° 等距柱状（equirectangular）图像，兼容主流全景查看器。

### 同一时刻如何保证

点击生成时生成不可变快照（`src/features/export/lib/snapshot.ts`），冻结机位、视角、作品可见性、
讲解字幕与播放进度、收藏注记和导览进度。导出在独立的离屏 WebGL 渲染器上基于该快照进行，
用户可以继续参观，实时场景的任何变化都不会影响进行中的任务；需要最新画面时再点一次
「按当前状态生成」即可，旧任务与新任务互不覆盖。

### 分块、接缝与遮挡

- 海报用 `PerspectiveCamera.setViewOffset` 把整帧切成**无重叠、无缝隙**的视锥矩形，
  每个像素恰好渲染一次，分块接缝、遮挡关系与金属/透明物体不会重复或缺失。
- 全景先渲染 6 个立方体面（同样分块），再在 CPU 侧装配为等距柱状图；
  面边界做钳制采样，并对近零方向分量归零，消除环绕接缝的 1px 取整差与黑洞。

### 容量与流畅度的明确限制

高分辨率、显存上限与持续交互流畅度无法同时无限满足，因此
`src/features/export/lib/capacity.ts` 会用一次性 WebGL 探针读取 `MAX_TEXTURE_SIZE`，
结合设备内存/核心数给出可选档位与分块边长，并在对话框中展示峰值临时内存：

- 任务**全局串行**，同一时刻只占用一个离屏 WebGL 上下文；
- 每完成若干分块主动让出主线程，参观交互保持流畅；
- 低端设备自动隐藏 8K / 300DPI 档位，探测失败时回退到最保守预算。

### 任务安全与失败恢复

- 取消、切换展览、页面卸载都会置位任务取消令牌，旧世代任务的结果绝不写入新任务；
- 浏览器回收三维上下文（`webglcontextlost`）时任务明确失败并提示重试，离屏资源立即释放；
- 渲染器、渲染目标、临时缓冲与对象 URL 在任务结束（成功/取消/失败）后统一回收；
- 导出失败不触碰实时展厅、讲解播放进度和 localStorage 中已写好的回顾注记。

## 测试

- `npm run test:math`：立方体投影、等距柱状接缝与分块覆盖的纯数学断言（Node）。
- `npm run test:unit`：13 组集成测试，用假渲染会话覆盖编排、取消、世代守卫、
  上下文丢失、资源回收与海报排版（Node + tsx，无需浏览器）。
- `npm run test:e2e`：真实无头 Chrome 的端到端渲染，需要与当前系统架构匹配的
  Chromium/Chrome（本仓库的沙箱为 arm64，无法运行 puppeteer 提供的 x86 二进制，
  故该脚本在有原生浏览器的环境执行）。
- `npm run typecheck` / `npm run build`：类型检查与生产构建。
